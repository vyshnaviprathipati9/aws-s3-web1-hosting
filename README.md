\## 📌 Project Overview



This project demonstrates how to host a static website using \*\*Amazon S3\*\* while implementing core AWS security and access control concepts.



The project covers the complete lifecycle of deploying a static website, configuring permissions, creating bucket policies, enabling website hosting, and implementing security best practices such as IP-based access restrictions.



\---



\## 🎯 Objectives



\- Create an Amazon S3 Bucket

\- Upload website files

\- Enable Static Website Hosting

\- Configure Bucket Policy

\- Configure Public Access

\- Create a Custom Error Page

\- Implement IP-based Access Restriction

\- Understand Amazon Resource Names (ARN)

\- Learn AWS Security Concepts
